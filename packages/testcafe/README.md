# @lambdatest/testcafe-driver

TestCafe driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [npm plugin for TestCafe integration with TestMu AI](https://www.testmuai.com/support/docs/npm-plugin-for-testcafe-integration-with-testmu/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/testcafe-driver
```

Requires `testcafe` as a peer dependency.

## Usage

See the [TestMu AI JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
