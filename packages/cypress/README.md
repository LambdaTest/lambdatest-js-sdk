# @lambdatest/cypress-driver

Cypress driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [Getting started with Cypress testing on TestMu AI](https://www.testmuai.com/support/docs/getting-started-with-cypress-testing/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/cypress-driver
```

Requires `cypress` as a peer dependency.

## Usage

See the [LambdaTest JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
