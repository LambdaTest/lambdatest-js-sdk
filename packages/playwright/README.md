# @lambdatest/playwright-driver

Playwright driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [Playwright testing on TestMu AI](https://www.testmuai.com/support/docs/playwright-testing/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/playwright-driver
```

Requires `playwright-core` as a peer dependency.

## Usage

See the [TestMu AI JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
