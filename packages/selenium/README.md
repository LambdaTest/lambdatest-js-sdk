# @lambdatest/selenium-driver

Selenium driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [Running your first Selenium test on TestMu AI](https://www.testmuai.com/support/docs/testmu-running-your-first-selenium-test/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/selenium-driver
```

Requires `selenium-webdriver` as a peer dependency.

## Usage

See the [LambdaTest JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
