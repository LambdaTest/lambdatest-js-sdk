# @lambdatest/wdio-driver

WebdriverIO driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [WebdriverIO automation on the TestMu AI Selenium Grid](https://www.testmuai.com/support/docs/webdriverio-with-selenium-running-webdriverio-automation-scripts-on-testmu-selenium-grid/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/wdio-driver
```

Requires `webdriverio` as a peer dependency.

## Usage

See the [TestMu AI JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
