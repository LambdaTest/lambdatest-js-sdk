# @lambdatest/puppeteer-driver

Puppeteer driver for the TestMu AI (Formerly LambdaTest) JS SDK.

## Documentation

- [Puppeteer testing on TestMu AI](https://www.testmuai.com/support/docs/puppeteer-testing/?utm_source=github&utm_medium=referral)

## Installation

```bash
npm install @lambdatest/puppeteer-driver
```

Requires `puppeteer` as a peer dependency.

## Usage

See the [TestMu AI JS SDK README](https://github.com/LambdaTest/lambdatest-js-sdk#readme) for setup, credentials, tunnel configuration and running tests.
